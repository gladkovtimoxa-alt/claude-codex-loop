# Инструменты и скрипты

Рабочие команды, выверенные на практике. Каждая учитывает ловушку, на которой
мы уже спотыкались — подробности в `../data/defects.jsonl`.

## Что чем запускать

| Задача | Оболочка | Почему именно она |
|---|---|---|
| Gradle, сборка | **PowerShell** | из Git Bash `cmd /c gradlew.bat` не находит рабочий каталог |
| `adb` с путями на устройстве | **PowerShell** либо Bash с `MSYS_NO_PATHCONV=1` **префиксом** | Git Bash подменяет `/sdcard/...` на `C:/Program Files/Git/sdcard/...`; через `export` переменная НЕ работает |
| Вытянуть бинарный файл | Bash или `adb pull` | PowerShell портит бинарники редиректом `>`, отдаёт UTF-16 с BOM |
| Запуск Codex | Bash | промпт передавать файлом, не строкой |

## Файлы

- `build-release.ps1` — сборка автономного APK
- `install-and-check.ps1` — установка и проверка, что приложение реально поднялось
- `codex.sh` — запуск Codex с обязательными флагами
- `emulator.sh` — поднять эмулятор как устройство на 8 ГБ
- `tap-by-text.sh` — атомарный дамп UI + тап по тексту/content-desc (без устаревших координат)
- `watch-jslog.sh` — ловля JS-логов на реальном устройстве (увеличивает буфер, фильтрует по тегу)
- `validate-memory.py` — проверка `data/defects.jsonl` **перед** коммитом: битый JSON, пустые обязательные поля, дубли `symptom`
- `fix-jsonl-escapes.py` — починка escape-последовательностей; на неоднозначных случаях отказывается угадывать
- `net-reach.sh` — матрица достижимости TCP с телефона через `nc` (не `/dev/tcp`, его в Android sh нет)

## Правила, которые экономят часы

- **«Подключено» не значит «авторизовано».** Рукопожатие транспорта
  завершается ДО проверки пользователя, поэтому клиент показывает успех и
  считает байты, пока сервер молча отбрасывает сессию. Перед выдачей любой
  конфигурации проверять, что её идентификатор реально зарегистрирован на
  сервере. Пусто — конфигурация мёртвая.
- **Выдача и регистрация — разные места, они расходятся.** Признак в
  настройках («новый транспорт включён») не гарантирует, что серверная
  сторона регистрирует клиента именно там. Проверять обе стороны на
  СВЕЖЕсозданной записи, а не на старых, попавших туда вручную.
- **Читать существующий служебный скрипт до того, как изобретать вызов.**
  Рабочий формат и грабли обычно уже описаны комментарием внутри него.
  Пропуск этого шага стоил часа на «команда вернула 0, но ничего не сделала».
- **Параметризованный скрипт не безопасен для любого значения параметра.**
  Запуск с другим значением собрался удалить всех пользователей, потому что
  источник данных отдаёт жёстко зашитое значение для всех записей. Всегда
  пробный прогон и чтение того, что он собрался удалить.
- **Падает только твой пробник — чини пробник.** Если через систему идёт
  живой трафик и он успешен, а отказ получаешь только ты, сломан инструмент
  диагностики, а не система.

- **Прямое указание «прочитай всё» не заменять выборкой.** Подмена чтения
  документации веб-поиском один раз дала уверенно НЕВЕРНЫЙ вывод («такой
  возможности нет»), который блокировал бизнес-задачу. Цена не в лишней
  работе, а в ложной уверенности.
- **Документация-приложение: искать встроенный контракт.** Если сайт отдаёт
  только вводную страницу и не даёт оглавления — сохранить страницу ЦЕЛИКОМ
  и вынуть из неё машинную спецификацию, считая скобки от якоря до баланса.
  Сохранение «только HTML» не годится: контракт лежит внутри скриптов.
  Так из семи разделов, видимых поиском, нашлось четырнадцать методов.
- **Справочник по API — генерировать, а не перепечатывать.** Рукописный
  расходится с источником на первой правке и становится вреднее отсутствия,
  потому что ему верят.
- **Проверять доступность чужого API читающим методом.** Список почти всегда
  безопаснее создания и отвечает на тот же вопрос, ничего не создавая в бою.
- **Скользящее окно не отвечает на вопрос «что нового».** Одна и та же запись
  выглядит новой при каждом опросе, пока не выйдет за границу. Нужен якорь:
  время выкатки или максимальный обработанный идентификатор.

- **Не приделывать `|| echo 0` к `grep -c`.** У него код возврата означает
  «нашлось ли», а не «сработал ли»: при нуле совпадений он ПЕЧАТАЕТ `0` и
  выходит с кодом 1, поэтому запасная ветка дописывает второй ноль и вывод
  превращается в мусор. Для подсчёта — `... | wc -l`: всегда одно число и
  всегда код 0.
- **Перед подсчётом грепом распечатать первые строки источника.** Ноль
  совпадений от неверного шаблона неотличим от настоящей пустоты. Дважды за
  один час это выглядело как «данные потеряны»: сначала инструмент не умел
  читать тип объекта, потом вывод оказался с табуляцией вместо `Ключ = значение`.
- **Измерить ущерб до починки.** Отсутствие страховочного механизма и наличие
  ущерба — разные вещи. Сначала посчитать, кого именно не хватает, и только
  потом решать. Автоматику, которая УДАЛЯЕТ, в одиночку не включать.

- **Память проверять ДО коммита, а не после.** Один раз сломанный
  `defects.jsonl` уже уехал в удалённый репозиторий именно потому, что
  проверка стояла после отправки. Порядок: `python scripts/validate-memory.py
  data/defects.jsonl` → и только при коде 0 `git commit`.
- **Валидатор не должен принуждать к выдумке.** `found_by` и
  `first_hypothesis` необязательны: часть записей — общие наблюдения и
  решения владельца, у которых их не было. Требовать эти поля — значит
  дописывать их задним числом и портить память ради зелёной галочки.
- **Отрицательный контроль.** Проверку тракта, доступа или самого
  инструмента сопровождать второй пробой с заведомо неверным параметром.
  Если «работает» и с ним — проверка меряет не то, что ты думаешь.
- **Отправку сверять по SHA.** Надпись `Everything up-to-date` уже приходила
  от двух разных сбоев. После push сравнивать локальный `HEAD` с веткой на
  удалённом и отправлять текущую ветку, подставляя её имя.

**Перед сборкой останови Metro** — он держит хендлы в `node_modules`, и Gradle
падает на удалении `libc++_shared.so`.

**После смены набора ABI удали `android/app/build`** — инкрементальная упаковка
ссылается на исчезнувшие архитектуры.

**После смены версии нативной зависимости удали `.cxx` во ВСЕХ пакетах**, а не
только в изменённых: ссылку на старый хэш держат и соседи.

**Не применяй `subst`** к каталогу проекта — одни и те же файлы становятся
доступны по двум путям и портят инкрементальный кэш Kotlin.

**На устройство пользователя ставь только release.** Debug не содержит JS и
требует Metro на компьютере: при каждом запуске без него — красный экран.

**Перед живым тестом на реальном телефоне увеличь буфер logcat** (`adb -s
<dev> logcat -G 16M`) и фильтруй по тегу (`logcat ReactNativeJS:V *:S`), не
grep по всему потоку. У реальных телефонов (особенно MTK) буфер бывает 256 КБ
и системный спам вытесняет JS-логи за секунды — используй `watch-jslog.sh`.

**Перед первым `git add -A` на свежем дереве сделай dry-run** (`git add -A -n`)
и `du -sh` по крупным каталогам. Легко случайно закоммитить `android/app/build`
(гигабайты) и `.models/` (скачанные GGUF/Vosk) — они должны быть в `.gitignore`.

**`fix-jsonl-escapes.py <файл> [--dry-run]`** — чинит невалидные JSON-escape
в JSONL-памяти. Повод: windows-путь и регулярка, записанные с одиночными
обратными слэшами, делают строку нечитаемой, а читатель, собирающий список
через генератор, падает целиком и теряет **всю** память, а не одну запись.
Скрипт удваивает только «голые» слэши, валидные записи не трогает, перед
записью кладёт бэкап. Прогонять после каждого дописывания в `data/`.

Читать память построчно с `try/except`, а не списком — тогда одна битая
запись не уносит остальные.

**`net-reach.sh [порт] [ip...]`** — матрица достижимости TCP с подключённого
телефона. Отвечает на вопрос, который надо задавать ПЕРВЫМ при жалобе «не
работает в сети»: сломан наш сервис или в этой сети вообще ничего не
открывается. Печатает вердикт — белый список оператора, мёртвая сеть или
нормальная линия.

Меряет через `nc`, а не через `/dev/tcp`: последнего в Android sh **нет**,
и попытка им пользоваться даёт таймаут по всем целям сразу — отказ инструмента
неотличим от искомого «всё заблокировано». В наборе всегда держится заведомо
рабочая цель: если и она SHUT, сломан инструмент, а не сеть.

Снимать при **выключенном VPN**, иначе меряется туннель.
