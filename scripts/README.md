# Инструменты и скрипты

Рабочие команды, выверенные на практике. Каждая учитывает ловушку, на которой
мы уже спотыкались — подробности в `../data/defects.jsonl`.

## Что чем запускать

| Задача | Оболочка | Почему именно она |
|---|---|---|
| Gradle, сборка | **PowerShell** | из Git Bash `cmd /c gradlew.bat` не находит рабочий каталог |
| `adb` с путями на устройстве | **PowerShell** либо Bash с `MSYS_NO_PATHCONV=1` **префиксом** | Git Bash подменяет `/sdcard/...` на `C:/Program Files/Git/sdcard/...`; через `export` переменная НЕ работает |
| Вытянуть бинарный файл | Bash или `adb pull` | PowerShell портит бинарники редиректом `>`, отдаёт UTF-16 с BOM |
| Запуск Codex | Bash | промпт передавать файлом, не строкой |

## Файлы

- `build-release.ps1` — сборка автономного APK
- `install-and-check.ps1` — установка и проверка, что приложение реально поднялось
- `codex.sh` — запуск Codex с обязательными флагами
- `emulator.sh` — поднять эмулятор как устройство на 8 ГБ
- `tap-by-text.sh` — атомарный дамп UI + тап по тексту/content-desc (без устаревших координат)
- `watch-jslog.sh` — ловля JS-логов на реальном устройстве (увеличивает буфер, фильтрует по тегу)

## Правила, которые экономят часы

**Перед сборкой останови Metro** — он держит хендлы в `node_modules`, и Gradle
падает на удалении `libc++_shared.so`.

**После смены набора ABI удали `android/app/build`** — инкрементальная упаковка
ссылается на исчезнувшие архитектуры.

**После смены версии нативной зависимости удали `.cxx` во ВСЕХ пакетах**, а не
только в изменённых: ссылку на старый хэш держат и соседи.

**Не применяй `subst`** к каталогу проекта — одни и те же файлы становятся
доступны по двум путям и портят инкрементальный кэш Kotlin.

**На устройство пользователя ставь только release.** Debug не содержит JS и
требует Metro на компьютере: при каждом запуске без него — красный экран.

**Перед живым тестом на реальном телефоне увеличь буфер logcat** (`adb -s
<dev> logcat -G 16M`) и фильтруй по тегу (`logcat ReactNativeJS:V *:S`), не
grep по всему потоку. У реальных телефонов (особенно MTK) буфер бывает 256 КБ
и системный спам вытесняет JS-логи за секунды — используй `watch-jslog.sh`.

**Перед первым `git add -A` на свежем дереве сделай dry-run** (`git add -A -n`)
и `du -sh` по крупным каталогам. Легко случайно закоммитить `android/app/build`
(гигабайты) и `.models/` (скачанные GGUF/Vosk) — они должны быть в `.gitignore`.
